방법론과 한계

  • 세전→세후 순서: 금융소득(원천 15.4% → 2,000만 초과분 종합과세, 인적공제 150만 적용 근사) → 연금소득(연 1,500만 임계) → 건보료(지역가입: 이자·배당 100%, 공적연금 50% 반영, 재산은 재산세 과표 기준 1억 공제 후 근사 점수환산, LTC 13.14%).
  • 재산보험료는 별표4 원문 60등급표로 계산합니다(시행령 [별표 4], 시행 2026.2.19본 — 국가법령정보센터 PDF 텍스트 추출, 삼쩜삼·전자신문 자료와 전 구간 교차 일치). 재산금액 = 재산세과표 + 전월세보증금×30% − 1억(−주택부채공제) 후 등급 lookup, 점수×211.5원. 초기 버전의 선형 근사식은 과표 9억에서 +347% 과대평가되어 폐기했습니다(G12 참조).
  • 국민연금은 내장 산식으로 계산합니다: 월액 = floor10(K̄×(A+B)×(P/240)/12)+부양가족. 계수 스택(~2007 1.8 / 2008~25 1.5→1.245 / 2026~ 1.29=3×43%)과 10원 절사 규칙까지 공단 예상연금 간단계산과 10원 단위 일치를 확인했습니다(2026-08-17, G1~G3 참조). 다만 B값은 "평균 실질 소득" 단일 입력 근사이며, 실제 과거 소득 이력(재평가)과 다를 수 있습니다.
  • 백테스트는 연 단위이고 한국 시계열은 KOSPI 1982~(PR, 배당 포함 토글은 2001~ TR 근사), 국고채 3년은 1998~(만기수익률 근사)입니다. 미국은 1928~(TR). 혼합 포트폴리오의 한국 30년 사이클은 두 시계열의 겹침이 짧아 개수가 부족하므로 주식 100%로 대체 표시합니다. 월 단위·CAPE 조건부 분석은 후속 과제입니다.
  • 국고채 3년은 만기수익률(YTM)이며 보유 총수익률의 근사입니다(듀레이션 손익 미반영). 미국 채권은 10년물 총수익률(CMT 근사)입니다.
  • 계류 이슈: 생산적금융 ISA(2026.12 국회 목표), 건보료 상하한 개편안, 배당가산율 11%(2027). 통과 시 rules 테이블 갱신 + 이 테스트가 검증합니다.
